# Opération : Arrêter le Générateur !

Jeu éducatif interactif pour enfants (~7 ans) sur la sécurité Internet.

Basé sur le cours "Operation: Stop the Generator!".

## Fonctionnalités
- Intro vidéo
- Personnage Mavi qui guide
- Choix interactifs (pièges, sites jumeaux, pubs, cadenas, hotkeys)
- Points & badges
- Effets sonores (Web Audio)
- Code secret final : 7-3-9-2-5

## Déploiement Vercel
1. Connecte le repo à Vercel
2. Framework Preset : Other / Static
3. Build Command : (vide)
4. Output Directory : (vide ou `/`)
5. Deploy

Les images et la vidéo doivent être dans les dossiers `imagine_images/` et `imagine_videos/`.

## Structure
- `index.html` → jeu principal
- `imagine_images/` → illustrations
- `imagine_videos/` → vidéo d’intro
